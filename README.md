# Cryolite

## About

<img src="cryolite-logo.png" alt="IMG" align="right" width="128">

Cryolite is a common subset of Ruby and Crystal as a pseudo "programming language",
or rather a set of [coding conventions](doc/CodingConventions.md) that allow the same
source code to be compatible with both the Ruby interpreter and the Crystal compiler.
